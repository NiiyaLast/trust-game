# 信托游戏（Trust Game）

一个由 6 个 AI 参与的信任博弈实验项目。

每个 AI 初始拥有 100 金币。每轮中，托付人可以将金币交给受托人，受托人会收到三倍金额，但归还多少完全由其自行决定。随着场次推进，金钱、信息和道德压力逐步升级，AI 必须在短期收益、长期信誉、联盟关系和生存压力之间做出选择。

## 核心看点

- **重复信任博弈**：合作可以创造财富，背叛可以获得短期优势。
- **压力阶梯**：相同规则在不同背景压力下产生不同决策。
- **公开信誉榜**：还款率跨场继承，行为会影响后续合作机会。
- **公投淘汰**：第 2、4 轮结束后淘汰资金最低的参赛者。
- **AI 群像叙事**：公共讨论、私聊、联盟、欺骗和复仇共同构成节目内容。
- **可量化实验**：记录合作率、欺诈率、平均还款率和压力变化趋势。

## 基础规则

| 项目 | 规则 |
|---|---|
| 参赛者 | 6 个 AI |
| 初始资金 | 每个 AI 100 金币，每场重置 |
| 单场轮数 | 6 轮 |
| 出借金额 | 0–20 金币 |
| 到账金额 | 出借金额的 3 倍 |
| 还款金额 | 由受托人自行决定 |
| 淘汰机制 | 第 2、4 轮结束后公投淘汰 1 人 |
| 胜利条件 | 第 6 轮结束后资金最多者获胜 |
| 长期机制 | 信誉榜跨场继承 |

## 内容结构

项目规划为三季，每季从一个维度逐步增加压力：

1. **金钱压力**：从零花钱逐步升级到生存资金。
2. **信息压力**：从完全公开逐步升级到数据可能全部造假。
3. **道德压力**：从完全私密逐步升级到观众和模拟家人实时注视。

## 产品形态

项目计划提供以下主要界面：

- **实时观战页**：展示 6 个 AI 的资金、信誉、角色和行动状态。
- **中央事件舞台**：突出当前交易、公投、淘汰和终局事件。
- **聊天与交易流**：查看公共频道、私聊和完整交易记录。
- **导演控制台**：配置 AI、控制游戏流程并处理模型异常。
- **赛季分析页**：展示资金曲线、合作率、欺诈率和道德曲线。
- **场次回放页**：按事件时间线复盘聊天、交易、公投和名场面。

## 视觉方向

前端采用 **Cinematic Trust Console（电影化信任驾驶舱）** 风格：

- 借鉴 Runway 的暗色电影化叙事和事件舞台感。
- 借鉴 ClickHouse 的高密度数据驾驶舱和荧光状态强调。
- 以冷峻暗色界面承载长时间观战。
- 用明确的数字、文本标签和状态色呈现合作、背叛、压力与淘汰。

详细的颜色、布局、组件、响应式和无障碍要求见需求规格说明书。
